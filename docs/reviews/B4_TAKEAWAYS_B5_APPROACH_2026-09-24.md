## 1. 배치 4가 알려준 것

**한 줄 요약**: 깨끗한 입력에서는 내부 기하가 출력 헤드에 더하는 정보가 없다. 기하의 가치는 **분포가 바뀔 때 초기 층에 남아 있는 "무엇이 바뀌었나"** 정보에 있다. 다만 그 정보의 상당 부분은 픽셀 통계에도 있다.

1. **신뢰도는 헤드로 충분하다.** 샘플별 "틀릴 것 같다" 경고는 로짓만으로 만들면 된다.
2. **네트워크는 마지막 블록에서 입력 정보를 버린다(붕괴).** 컨트롤러가 원하는 정보는 그 버려진 정보(노이즈, 블러, 노출 등)다. 그래서 감시는 **붕괴 이전 층**에서 해야 한다.
3. **초기 층 정보의 상당 부분은 픽셀에도 있다.** 앞으로 모든 비교에 픽셀 기준선이 필수다.
4. **"이 변화가 모델에게 해로운가"는 아직 입증되지 않았다.** 피해 전 선행 경고와 무해한 변화 무시 모두 실패했다.
5. **붕괴는 같은 계열 안에서만 예측 가능하다.** 크기가 커질수록 붕괴는 단조롭게 강해진다. 하지만 계열 간 수준은 다르고, 붕괴가 강해진다고 오염에 강해지지 않는다.
6. **오경보율 보정은 모델을 넘어 전이된다.** 깨끗한 held-out 데이터로 보정하면 재튜닝 없이 12개 아키텍처에서 FPR이 유지된다.

## 3. 배치 5 접근

### 방향 전환의 이유

- 배치 1-4는 **이름 붙인 축을 확인**했다. 18개 요인과 오염 종류다.
- 최종 목표(여러 감각을 공유 공간에서 합치기)에서는 소리나 촉각의 축에 미리 이름을 붙일 수 없다.
- 그래서 먼저 **"공간을 있는 그대로 기록하고, 축을 스스로 찾아내는 도구"**를 이미지에서 검증한다.

### Map Protocol

```
[0 질문 카드] → [1 자극 설계] → [2 추출] → [3 축 없는 기록] ─(안정성 게이트)─┐
                     ↑                                                     ↓
                     └── [6c 조작화] ← [6b 비평] ← [6a 후보 제안] ← [6 잔여 구조] ← [5 축 채점] ← [4 축 라이브러리]
                                                   ↓
                                  [7 사전 등록 확인] → [8 지도 카드]
```

**1 자극 설계**
- 모든 입력에 완전한 메타데이터를 붙인다.
- 최소 쌍(요인 하나만 변경), 연속 스윕, 요인 교차를 쓴다.
- 행은 참조, 발견, 봉인 확인으로 나눈다.

**2 추출**
- 모든 층을 추출한다.
- 기준 뇌 셋을 고정한다: 픽셀, 무작위 초기화, 헤드.

**3 축 없는 기록**
- 층별 거리 행렬과 kNN 그래프를 만든다. 좌표에 의존하지 않는 형식이다.
- 안정성 게이트: bootstrap, 시드 간 일치, 정보 보존, 기준선 분리

**4-5 축 라이브러리와 채점**
- 축은 메타데이터의 함수로 정의한다. 헤드도 하나의 축으로 등록한다.
- 채점은 RSA, 탐침, 최소 쌍 이동, 스윕 곡률, 층 궤적으로 통일하고 기준 뇌 대비로 보고한다.

**6 잔여 구조와 자동 고리**
- 알려진 축으로 설명되지 않는 구조에서 후보 축을 제안한다. 출처 후보는 잔여 방향, 기술자 은행, 시각-언어 모델 서술, 민감도, 이상치, 문헌이다. 배치 5에서는 잔여 방향, 기술자 은행, 민감도 세 개만 쓴다.
- 비평 → 자극 생성 → 발견 행 선별을 반복한다.

**7-8 확인과 지도 카드**
- 봉인 행에서 사전 등록 확인을 한다.
- 모델별 지도 카드에 층 × 축, 설명 비율, 컨트롤러 열을 담는다.

### 배치 5 트랙 (외부 리뷰 반영, 2026-09-24)

실행 순서는 M0 → M1 → M2 → M3이다. 중요도는 **M2 > M3 > 컨트롤러 연결 > M1**이다.

| 트랙 | 내용 | 성공 기준 |
|---|---|---|
| **M0** | 배치 4 step E 산출물과 이 문서, 설계 초안을 커밋 | — |
| **M1** 프로토콜 검증 (관문) | 픽셀 요인 6개 × 강도 7단계. ResNet20 s1-s4, ResNet56 s1/s2, 기준 뇌 셋 | 안정성 게이트 통과, 심어둔 축 6개 회수, 기준선 분리. **기여로 세지 않음** (sanity check) |
| **M2** 숨긴 축 재발견 (최우선) | 6개 요인을 하나씩 숨기고 자동 고리 실행. 대조 조건은 **"숨긴 것 없음"**과 무작위 네트워크 | 아래 6단계 모두 충족 |
| **M3** 오염 × 모델 크기 | CIFAR-10 hub 17개로 발견. **CIFAR-100 hub 19개, 새 자극, 새 오염**으로 봉인 확인. VGG11은 부차 과제 | P1에 고정한 예측이 봉인 자료에서 맞음 |

**M2 성공 = 이름 붙이기가 아니라 예측 확인.** 6단계를 모두 충족해야 한다.
1. 잔여 구조 또는 민감도 경로에서 숨긴 요인에 대응하는 구조를 찾는다. 기술자 은행 경로는 인정하지 않는다.
2. 그 구조에서 후보 요인을 만든다.
3. 새 최소 쌍과 스윕 자극을 생성한다. 기술자 은행에는 숨긴 요인의 생성 파라미터를 넣지 않는다.
4. 표현이 움직일 방향, 순서, 씻겨 나가는 층을 사전 예측한다.
5. 봉인 행에서 예측을 확인한다.
6. 무작위 네트워크에서는 같은 구조가 재현되지 않는다.

"재발견"의 판정 기준(숨긴 요인 방향과의 부분공간 정렬 임계값)은 P1에 고정한다. "숨긴 것 없음" 조건에서 나온 "새 축"은 거짓 발견으로 센다.

**M3 봉인 자료를 바꾼 이유.** CIFAR-10 hub 17개의 CIFAR-10-C 결과와 VGG11 이상치는 배치 4에서 이미 읽었다. 그래서 확인에는 다음만 쓴다.
- 처음 만드는 자극
- CIFAR-10-C에 없는 새 오염 변환
- 같은 upstream의 **CIFAR-100 hub 모델 19개**: 같은 5개 계열이고 한 번도 측정하지 않았다. 2026-09-24에 release API로 존재를 확인했다(총 약 0.5 GB).

### 축 분류와 점수

**두 개의 독립 축** (리뷰의 A→B→C 단계를 수정):
- **출처**: 픽셀에 원래 있음 / 구조가 만듦(무작위 네트워크에도 있음) / 학습이 만듦 → **어디서 읽을지**(비용)를 정한다.
- **결과**: 성능과 무관 / 손실과 연관 / 행동 필요성과 연관 → **컨트롤러 후보 여부**를 정한다.
- 픽셀에서 보이는 축도 결과가 있으면 컨트롤러 입력이 된다(픽셀에서 읽으면 됨).
- "무관"으로 확정된 축은 **억제 목록**으로 쓴다. 무해한 변화 무시(HOLD)와 F2 게이팅의 근거가 된다.

**두 개의 점수를 분리한다.**
- 표현 점수: 안정성, 시드 일치, 분리도, 스윕 단조성·곡률, 층 궤적
- 효용 점수: 손실 연관, 실패 위험 연관, 픽셀 + 헤드 대비 증가분, 모델 간 전이
- 선행 시간은 **배치 5에서 측정 불가**(N/A)로 명시한다.
- 표현 점수가 높아도 효용 점수가 낮으면 컨트롤러 후보가 아니다.

**주 대비는 하나로 둔다**: 표현이 **(픽셀 + 헤드)** 위에 더하는 증가분. 나머지 조합은 INFO로 기록한다.

### 컨트롤러와의 연결 (최종 목표 추적)

- **지도 카드의 컨트롤러 열**: 감시 추천 층, 픽셀 대체 가능 여부, 결과 분류
- **두 개의 성적**: 1차 질문(지도·축)과 최종 목표(컨트롤러 기능표)를 따로 매기고, 어느 칸이 움직였는지 보고한다.

### 이번에 하지 않는 것

- **DINO/CLIP**: 배치 6에서 헤드 없는 인코더의 지도 일반성으로 다룬다.
- **시각-언어 모델 기반 후보 제안**: 배치 6으로 미룬다. 배치 5의 후보 경로는 잔여 방향, 기술자 은행, 민감도 세 개로 제한한다.
- 생성 모델 기반 의미 편집, 다감각과 시간축, 폐루프
- 배치 4의 컨트롤러 효용 후속 항목. 단, 픽셀 기준선과 보정 행 검사는 흡수한다.

### 외부 리뷰에서 버린 것

- **"새로움", "강한 연구 기여"라는 평가 틀**: Atlas의 기준은 기능적 가치다. 다만 리뷰가 요구한 실질(표본 밖 예측, 기준선 분리)은 유지한다.
- **"성능과 연결 안 되면 컨트롤러와 무관"**: 무해한 축의 억제 목록도 컨트롤러 가치가 있다.
- **후보 경로를 줄여서 자유도를 통제하자는 방식**: 경로를 줄이는 대신 봉인, 예산 상한, FDR, 사전 고정 기준으로 통제한다. 경로 제한(3개)은 실무상의 선택이다.
